# Leel AI 🌍

Application mondiale d'assistant intelligent.

Leel AI est un assistant qui aide, répond, explique et accompagne les utilisateurs partout dans le monde.

## ✨ Fonctionnalités
- Répondre aux questions
- Aider à apprendre
- Expliquer simplement
- Discuter comme un ami

## 🚀 Technologies
- React
- TypeScript
- Tailwind CSS
